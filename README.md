# Introduction
As I try and refresh existing skills and up skill in new areas, I have been taking courses on Udemy that I am then applying to my own personal project called 'Looking to play'.

Looking to play is a way for me to take what I am learning and applying it to something I have an interest in with the broader aim of me moving away from the low-code development I have been doing for a few years now, back into traditional high-code development.

One element of the project will include the use of JUnit and Mockito, which I am learning on [Udemy](https://www.udemy.com/course/spring-boot-unit-testing/?couponCode=MT260907G2).
